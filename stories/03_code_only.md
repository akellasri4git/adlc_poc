# ADLC-103: Chat app message handling

## Description
As a developer, I want only the code for a simple chat app, so that I can try it out quickly. The design is already agreed, so no design work is needed.

## Acceptance Criteria
- A user can join a chat room with a display name
- A user can send a message to everyone in the room
- Every message shows the sender's name and a timestamp
- A user can see the last 50 messages when they join
