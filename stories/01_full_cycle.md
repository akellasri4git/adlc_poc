# ADLC-101: To-do list REST API

## Description
As a busy professional, I want a REST API for managing my to-do items, so that any client app can create, view, update and delete my tasks.

Please provide the design first and then the implementation.

## Acceptance Criteria
- A user can create a task with a title and an optional due date
- A user can list all tasks and filter them by status (open / done)
- A user can mark a task as done
- A user can delete a task
- Invalid input returns a 400 response with a clear error message
